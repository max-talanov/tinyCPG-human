# Paper directory

LaTeX scaffold for the tinyCPG paper. Target journal:
**PLOS Computational Biology** (backup: Frontiers in Computational
Neuroscience). See `novelty_vs_zhang2021.md` for the positioning
argument.

Only Methods and Results are currently active in `main.tex` (Abstract,
Introduction and Discussion are drafted but commented out — see
`sections/*.tex`). Results are described on a $5\times5$ grid of five
locomotion modes crossed with five STDP learning rates, using the canonical
sensory-sited model (see `../CLAUDE.md` and `../MN5_RUN.md`).

## Layout

```
paper/
├── main.tex                    ← top-level LaTeX file
├── refs.bib                    ← bibliography (BibTeX)
├── Makefile                    ← build helper (make pdf | quick | clean)
├── README.md                   ← this file
│
├── sections/                   ← one .tex per section, \input'ed from main.tex
│   ├── abstract.tex            (drafted, not yet active)
│   ├── introduction.tex        (drafted, not yet active)
│   ├── methods.tex             (active)
│   ├── results.tex             (active)
│   ├── discussion.tex          (drafted, not yet active)
│   └── supplementary.tex       (active — delays table + algorithm pseudocode)
│
├── figures/                    ← .png files referenced by \includegraphics
│                                  (the single source of truth for the paper's
│                                  figures — regenerated by ../scripts/*.py,
│                                  see "Regenerating figures" below)
│
├── connectivity_table.tex      ← weight/delay table, \input'ed by supplementary.tex
├── mode_lambda_table.tex       ← 5x5 mode x lambda comparison table, \input'ed by results.tex
├── params.{md,tex,csv}         ← parameter table (from ../scripts/cpg_param_table.py)
├── methods_skeleton.md         ← prose-writing notes for Methods (long-form)
└── novelty_vs_zhang2021.md     ← positioning vs. the Rybak/Zhang lineage
```

## Build

```bash
cd paper
make pdf            # full latexmk pass with bibliography
make quick          # single pdflatex pass (faster, no bibtex)
make clean          # remove latex aux files
```

For Overleaf, zip `main.tex`, `sections/`, `figures/`, `refs.bib`,
`connectivity_table.tex`, `mode_lambda_table.tex` and `params.tex` from the repo
root:
```bash
cd paper && zip -r ../tinyCPG_overleaf.zip main.tex sections figures refs.bib \
    connectivity_table.tex mode_lambda_table.tex params.tex -x "*.DS_Store"
```

## Regenerating figures

Figures are generated by the scripts in `../scripts/` (run from the repo root,
after pulling results back from MN5 — see `../MN5_RUN.md` §4 for the full
per-figure command list). Quick reference:

| Script | Figure(s) |
|---|---|
| `scripts/cpg_architecture_diagram.py` | `fig_architecture_implemented.png` |
| `scripts/cpg_connectivity_figure.py` | `fig_connectivity.png` |
| `scripts/cpg_stdp_weight_matrix.py` | `fig_stdp_weight_matrix.png` |
| `scripts/cpg_stdp_weights_grid.py` | `fig_stdp_weights_grid.png` |
| `scripts/cpg_force_stages.py` | `fig_force_stages_lam1em{2..6}.png` |
| `scripts/cpg_network_matrix.py` | `fig_network_matrix_lam1em{2..6}.png` |
| `scripts/cpg_mode_lambda_summary.py` | `fig_mode_lambda_heatmaps/trends.png` + `mode_lambda_table.tex` |
| `scripts/cpg_epidural_contrast.py` | `fig9_epidural_contrast.png` |
| `scripts/cpg_param_table.py` | `params.tex` |

`fig1_schematic.png` is a hand-drawn conceptual diagram, not script-generated.

Superseded generators (from earlier paper iterations, no longer used) live in
`../scripts/legacy/` for reference only.

## Submission switch

When ready to submit, replace the generic preamble in `main.tex`:

- **PLOS Computational Biology:**
  `\documentclass{plos2015}` (from <https://journals.plos.org/ploscompbiol/s/latex>)
  and `\bibliographystyle{plos2015}`.

- **Frontiers in Computational Neuroscience:**
  Use the Frontiers Word template instead — they accept LaTeX but require
  a final Word submission via their portal. Easiest path: produce a
  clean PDF here, then paste into the Frontiers Word template.
